## 👋 About Me

日本の国立大学で**情報科学**を専攻している学部生です。  
**FPGA / SoC / 組込みシステム / 表示系 / システムソフトウェア**を中心に、  
ハードウェアからソフトウェアまで一貫して設計・実装することを得意としています。

RTL設計やデバイスドライバ、組込み Linux、ネットワーク、可視化・UI まで含めた  
**エンドツーエンドなシステム構築**に強い関心があります。
